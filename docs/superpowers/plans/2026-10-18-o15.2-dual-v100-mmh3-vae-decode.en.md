# Raylight 1.18.0 / O15.2 Dual-V100 MiniMax H3 VideoVAE Decode Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Parallelize Director MiniMax H3 VideoVAE temporal chunks across the main GPU0 process and rank-1 Ray worker without changing ComfyUI or Director, then certify behavior, quality, performance, lifecycle, and fallback.

**Architecture:** An execution-scoped Raylight bridge preloads a CPU VAE on rank 1, intercepts standard Director `VAEDecode` calls only for a Ray model proxy, decodes even and odd temporal chunks concurrently, and reproduces the official overlap merge. Unsupported and failing paths call the original decoder.

**Tech Stack:** Windows, Python 3.12.10, PyTorch 2.12.0+cu126, ComfyUI, Ray 2.57.0, dual Tesla V100-SXM2-16GB TCC, pytest, xFormers.

**Spec:** `docs/superpowers/specs/2026-10-18-o15.2-dual-v100-mmh3-vae-decode-design.en.md`
