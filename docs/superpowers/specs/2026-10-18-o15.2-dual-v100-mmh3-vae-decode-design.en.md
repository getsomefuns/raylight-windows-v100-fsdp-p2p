# O15.2 Dual-V100 MiniMax H3 VideoVAE Decode Design

## Goal

Parallelize MiniMax H3 VideoVAE temporal decoding across two V100 GPUs through Raylight's Director adapter, without changing ComfyUI or MiniMaxH3Director source and without adding workflow wiring. Preserve the official 256-pixel spatial tiles, temporal overlap blend, FP16 weights, and xFormers attention semantics.

## Architecture

The Ray MODEL Adapter installs an execution-scoped `VAEDecode` bridge. At Director entry it obtains the backing VAE path from ComfyUI's `cached_patcher_init` metadata and asks rank 1 to preload only the CPU VAE object in a background thread while text encoding and sampling continue. During decode, the existing main-process VAE on GPU0 handles even temporal chunks and the cached rank-1 VAE handles odd chunks. Raw chunks return to the CPU and are merged with the official five-frame overlap rule before float32 `[0,1]` finalization.

The bridge is fail-open. A non-Ray model, one GPU, an unsupported VAE, missing loader metadata, a short latent, or a remote error uses the original `VAEDecode`. The context is cleared at the end of every Director execution, preventing cross-workflow actor or VAE cache contamination.

## Scope and acceptance

- Base Director decode, Refine, and FaceRefine calls that use standard `VAEDecode` are covered. SelfLift's direct internal `vae.decode()` calls and AudioVAE remain native.
- Match the 107-frame 1920×1088 native output shape, PSNR≥58 dB, and maximum absolute error≤0.003.
- Warm decode≤42 seconds, target38 seconds, and at least35% faster than the measured64.08-second native baseline.
- If preload is hidden by sampling, first decode≤45 seconds; decode VRAM≤7 GiB per GPU.
- Five consecutive segments without worker multiplication or monotonic memory growth, with safe native fallback on every unsupported or failed path.

No ComfyUI or Director edits, tile-size or precision changes, forced NVLink transfer, or attribution of Director PR #182's post-decode color matching to this neural VideoVAE benchmark.
