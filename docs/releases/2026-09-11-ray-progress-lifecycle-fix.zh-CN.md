# 1.14.1：Ray 进度条生命周期修复

本补丁修复 Windows ComfyUI 长时间运行并跨工作流复用 Ray worker 时，已经完成的旧采样进度条仍被反复绘制的问题。

## 根因

Raylight 的 `tqdm.auto` 兼容层在普通迭代结束后没有显式关闭 Ray 的远程进度条。Ray 驱动因此继续把旧进度条视为活动状态，每次新日志或新采样刷新时都会再次显示旧 PID，并让其已用时间持续增长。旧 PID 实际已经退出，这不是额外 worker 泄漏。

## 修复

- 迭代正常完成、异常退出或提前关闭时都会关闭远程进度条。
- 关闭操作具有幂等性，避免上下文管理器再次关闭时重新创建幽灵进度条。
- 保留一对 Ray worker 跨工作流复用的既有行为，以继续支持模型缓存、Director 分段缓存和热启动性能。
- 新增回归测试覆盖远程进度条自动关闭和重复关闭保护。

## 无关问题

ComfyUI `SaveVideo` 只允许将相对路径写入 `ComfyUI/output`。把文件名前缀设置为诸如 `E:\\short-drama\\ep01` 的绝对路径会被 ComfyUI 0.31 拒绝；应使用 `video/short-drama/ep01` 一类相对前缀。该限制不来自 Raylight。
