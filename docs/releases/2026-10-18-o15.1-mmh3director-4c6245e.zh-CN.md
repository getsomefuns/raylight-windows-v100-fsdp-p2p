# Raylight 1.17.1：MiniMaxH3Director 4c6245e 兼容认证

## 版本目标

本版把已验证的官方 MiniMaxH3Director 坐标从 `8151b291fcacee5ddb70c6493eaed4f831bc6867` 更新为 `4c6245e518dd8a494f3afc4f3cccd53f22d82d10`。Director 保持官方干净工作树；没有修改 ComfyUI、Director、SOL 或 TE-Speed 源码。

## 上游实际变化

两者之间只有一个提交，修改 `web/js/minimax_i18n.js` 与 `web/js/minimax_pack.js`。新版在导演包导入/导出期间显示上传、解压、统计、打包、下载、保存与写入时间轴进度，避免大包操作看起来卡死。

这次更新没有改变 Python 节点、`sample_single_stage` 签名、Refine、SelfLift、FaceRefine、分段 LoRA、缓存格式、VAE 或音频路径。Raylight 因此只更新兼容坐标和测试，不增加没有消费者的 worker 协议或采样分支。

## VAE 解码边界

MiniMaxH3Director PR #182 优化的是 VAE 已经输出图像之后的连续片段 opening-grade 匹配：把逐帧 CPU box blur 改为 GPU 批处理，并复用引导帧低频结果。它不执行 VideoVAE 神经网络解码，因此不能消除本机日志中约 66 秒的 107 帧 1920×1088 VideoVAE 解码，也不会缩短没有触发 opening-grade 的首段生成。

## Raylight 改动

- `SUPPORTED_DIRECTOR_COMMIT` 更新到 `4c6245e`；签名仍逐字段 fail closed。
- 项目版本更新到 1.17.1。
- 保留 O15 的分段 LoRA、SelfLift/Refine、实时预览、SOL/TE、生命周期与 Windows CUDA P2P/FSDP 实现。
- 更新中英文 README、计划、发布说明和验收记录。

## 验证结果

- Director 官方测试：`2 passed, 10 subtests passed`；两个新增 JS 文件通过 `node --check`。
- Raylight Director/生命周期/部署专项：`151 passed`。
- Raylight 全量：`769 passed, 35 subtests passed`。
- 两段 1-step 双卡实机回归：146 帧、864×480、24 fps；两个远程 operation 都声明 `ranks=2`，复用同一对 worker；GPU 峰值 9293/9269 MiB、利用率峰值 99%/97%。
- 输出 H.264 146 帧、AAC 32 kHz 双声道，视频与音频均完整解码。

完整数据见 [O15.1 测试记录](../testing/minimax-h3/O15_1_MMH3DIRECTOR_4C6245E_2026-10.zh-CN.md)。
