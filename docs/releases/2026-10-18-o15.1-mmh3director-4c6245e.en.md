# Raylight 1.17.1: MiniMaxH3Director 4c6245e compatibility certification

## Release goal

This maintenance release moves the validated official MiniMaxH3Director coordinate from `8151b291fcacee5ddb70c6493eaed4f831bc6867` to `4c6245e518dd8a494f3afc4f3cccd53f22d82d10`. Director remains a clean upstream checkout; ComfyUI, Director, SOL, and TE-Speed source are unmodified.

## Upstream delta

The range contains one commit touching `web/js/minimax_i18n.js` and `web/js/minimax_pack.js`. Director-pack import/export now reports upload, extraction, scan, pack, download, save, and timeline-apply progress. No Python node, sampling signature, Refine, SelfLift, FaceRefine, per-segment LoRA, cache format, VAE, or audio contract changed.

Raylight therefore updates its validated commit and tests without adding a synthetic worker protocol or sampling branch.

## VAE boundary

MiniMaxH3Director PR #182 accelerates continuity opening-grade matching after VAE images already exist. It replaces per-frame CPU box blur with a batched GPU path and reuses the guide-frame low-frequency result. It does not execute neural VideoVAE decode, so it cannot remove the measured roughly 66-second 107-frame 1920x1088 VideoVAE decode or accelerate a first segment that does not run opening-grade matching.
