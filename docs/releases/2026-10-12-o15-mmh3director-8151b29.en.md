# Raylight 1.17.0: MiniMaxH3Director 8151b29 and per-segment LoRA

## Scope

This release moves the validated MiniMaxH3Director coordinate from upstream `576424f` to `8151b291fcacee5ddb70c6493eaed4f831bc6867`: 25 commits, 32 files, 3,624 insertions, and 332 deletions. Neither Director nor ComfyUI source is modified. Raylight changes only its MODEL proxy, worker request protocol, tests, benchmark tooling, example workflow, and documentation.

The Director update directly provides Refine layout realignment; selected-run, tail-lock, and continuity fixes for FL2V; raw/FFV1 lossless frame cache; custom cache namespaces including node IDs; the selected-segment one-frame placeholder fix; decoded-audio sample-rate preservation; segment prefetch cleanup; per-segment LoRAs; and UI/public-parameter updates. These remain Director main-process features and are not presented as Raylight acceleration.

## Raylight adaptation

The official per-segment LoRA path calls `ModelPatcher.clone() + add_patches()`. Raylight's main-process Ray MODEL proxy intentionally carries no Diffusion weights, so 1.17.0 uses a descriptor bridge:

1. The main process validates up to eight active non-zero LoRA rows and resolves their paths under `models/loras` without loading weights.
2. The current stack travels with each first-pass, SelfLift, or Refine request to both workers.
3. Each worker applies it after the SigmaShift temporary clone and before optional SOL/TE replay.
4. The global `RayLoraLoader` remains the base stack; segment patches exist only on the current temporary sampling model.
5. An empty or different next-segment stack starts again from the base model, so patches cannot accumulate.
6. Each worker retains at most two recent CPU state dicts and clears that cache on model/list changes and worker shutdown.

Ordinary ComfyUI MODEL objects still use Director's official implementation. Only the exact Ray proxy is intercepted, and remote failure remains fail-closed with no silent GPU0 fallback.

## Hardware results

The unchanged O14 REF2VA 864x480, 124-frame, 24 fps, Turbo4 + SOL + SelfLift + Refine workflow completed three dual-rank operations on the new Director. End-to-end time was 337.52 seconds and sampling was 152.37 seconds. GPU peaks were 9351/9329 MiB; physical/commit peaks were 64925.77/113409.72 MiB with zero pagefile use. All 124 frames were unique, and audio decoded with zero NaN/Inf. Against the published O14 cold record, sampling was 5.94% slower and end-to-end was 16.97% slower. These are independent cold observations, not an attribution to one upstream commit or a speed claim.

The new two-segment workflow keeps the global REF2VA Turbo4 stack, adds a 0.6 realism LoRA only to segment one, and leaves segment two empty. A one-step routing/isolation smoke produced two dual-rank operations on the same worker pair. The 104 segment patches loaded once on each rank for segment one and did not reload or appear in segment two. End-to-end time was 205.67 seconds, sampling was 53.79 seconds, GPU peaks were 9431/9407 MiB, and physical/commit peaks were 71045.47/117168.31 MiB with zero pagefile use. The output is H.264 864x480 at 24 fps, 146/146 unique frames, with decodable stereo AAC at 32 kHz.

Director aligned the requested 62+62 input frames to 73+73 model frames. This is the official timeline plan, not duplicate Raylight sampling.

## Additional fix

The multi-segment run exposed a benchmark-only pairing defect. Ray forwards actor stdout independently, so two profile lines from one operation may arrive more than two seconds apart. The old fixed-time-window grouping invented extra operations. Each profile is now anchored to the latest sampling-preparation start from the same rank; preparation diagnostics still require both ranks for every operation.

## Boundaries

- Director `8151b29`, legacy bridges, SelfLift, same-checkpoint Refine, FaceRefine interfaces, Semantic Bridge, SOL, TE, live preview, and continuity remain available.
- Per-segment LoRA applies only to the Diffusion Model. Text Encoder/VAE LoRAs and custom Refine with another checkpoint are outside this guarantee.
- Raw/FFV1 cache, cache namespaces, selected-run export, audio sample rate, and prefetch cleanup remain Director main-process work; Raylight validates coexistence, not acceleration.
- A verified `576424f` Git bundle is retained locally under ignored `.local/backups/director/` for rollback and is not committed.
